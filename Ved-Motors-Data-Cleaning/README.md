# Ved Motors – Real-World Data Cleaning using Pandas

## 📌 Project Overview

This project focuses on cleaning and preprocessing a real-world vehicle sales dataset from a dealership environment.

The dataset contained inconsistent values, missing data, spelling mistakes, formatting issues and unnecessary columns.

I used Python and Pandas to explore, clean, standardize and prepare the dataset for further analysis.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Microsoft Excel

## 🔍 Data Cleaning Performed

- Loaded and inspected the Excel dataset
- Explored rows, columns and data types
- Identified missing values
- Removed unnecessary columns
- Removed an unwanted record
- Standardized customer names
- Standardized company and dealer names
- Corrected spelling inconsistencies
- Standardized vehicle model names
- Standardized vehicle base values
- Cleaned mobile number formatting
- Cleaned vehicle identifiers
- Standardized payment type values
- Formatted date columns
- Replaced missing values with `Not Provided`
- Performed final data validation
- Exported the cleaned dataset to Excel

## 📊 Dataset

The project is based on real-world vehicle sales data.

For privacy reasons, personally identifiable customer information should not be published in the public repository.
