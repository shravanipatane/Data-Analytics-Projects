# Week 3 – Advanced Data Analysis & Visualization in Logistics

## 📌 Objective

The objective of Week 3 was to deepen analytical skills by exploring,
analyzing, and visualizing logistics data using Python.

The project focuses on identifying operational inefficiencies,
cost drivers, delivery trends, and potential bottlenecks through
exploratory data analysis and visualization.

---

## 📊 Dataset

A hypothetical logistics dataset was simulated containing variables
related to:

- Delivery time
- Shipment volume
- Transportation cost
- Vehicle type
- Delivery zone
- Time slot
- Delivery status
- Distance travelled

---

## 🔍 Exploratory Data Analysis

The analysis included:

- Descriptive statistics
- Mean, median and standard deviation
- Distribution analysis
- Correlation analysis
- Trend analysis
- Cost analysis
- Delivery performance analysis
- Zone and time-slot analysis

---

## 📈 Visualizations

The project includes visualizations for:

1. Correlation between logistics variables
2. Delivery-time distribution
3. Transportation-cost distribution
4. Cost by vehicle type
5. Daily delivery trends
6. Zone × time-slot performance
7. On-time delivery trends
8. Operational bottlenecks

Each visualization was selected to answer a specific
logistics/business question.

---

## 💡 Key Business Questions

### 1. What factors influence delivery time?

### 2. What are the major transportation cost drivers?

### 3. Which vehicle type is more cost-efficient?

### 4. Which zones and time slots experience bottlenecks?

### 5. How does delivery performance change over time?

### 6. Where can operational efficiency be improved?

---

## 🧠 Key Insights

- Distance travelled showed a strong relationship with delivery time.
- Distance was also an important driver of fuel/transportation cost.
- Vehicle type had a measurable impact on cost efficiency.
- Certain zone and time-slot combinations showed weaker
  delivery performance.
- Visualization helped identify operational bottlenecks
  that may not be obvious from summary statistics alone.
