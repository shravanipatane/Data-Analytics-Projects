This repository contains my work completed during my **Virtual R Data Analyst Internship**, covering practical data analysis tasks using **R**.

The internship consists of four weeks of progressively structured tasks, starting with data cleaning and exploratory analysis and progressing toward data visualization, statistical analysis, predictive modeling, and comprehensive data reporting.

**Role:** R Data Analyst Intern
**Domain:** Data Analytics
**Primary Programming Language:** R
**Duration:** 4 Weeks

* Clean and preprocess real-world datasets
